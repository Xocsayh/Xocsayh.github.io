Turkish Pentest Wordlists

An open-source, Turkish-focused wordlist collection for web security testing (~315K entries).

+

Why I Built It

Almost every public wordlist (SecLists, etc.) is English-only. Turkish systems use terms like yonetim, yukle, bayi, fatura that those lists miss — a real blind spot. So I built and open-sourced a Turkish-focused set.

Highlights

  • ~315,000 entries: directories, files, subdomains, parameters
  • Sensitive-file patterns (.env, config.php.bak, yedek.sql)
  • Includes a Python generator to grow the lists
